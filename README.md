# UTT (university-task-tracker)
Система просмотра невыполненных задач/работ для студентов.


## Overview
Цель системы - понизить количество пропущенных дедлайнов выполнения лабораторных/курсовых работ студентами, собрать все задачи в один удобный интерфейс. Текущий способ организации слабо справляется со своей задачей - задания не организованы, находятся в разных интерфейсах/чатах/приложениях, что приводит к потере времени при поиске, а иногда и пропуску сдачи работ.  

## Target users
Система в первую очередь предназначена для помощи студентам путём организаций задач в одном интерфейсе, следовательно снижения траты времени на их поиск.

## Core features
1. Добавление задач
2. Просмотр сроков их выполнения
3. Просмотр статуса задач (done/pending)

## Scope and limitations
1) Комментарии к заданию / вопросы к заданию (обратная связь с преподавателем касаемо конкретной работы)
2) Интеграция эл. дневника
3) Установка приоритетов выполнения заданий
4) Система напоминаний
5) Личные заметки к заданиям
